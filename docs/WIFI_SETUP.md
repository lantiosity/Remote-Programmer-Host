# WiFi 配置

上位机 0.2.3 配合固件 0.1.3 使用，支持 USB、BLE 和 CH343 控制台配网。USB 以固件声明的 `wifi_setup:1` 能力判断支持情况，并兼容未声明该字段的历史开发版 1.3.0。BLE 配网要求设备提供对应服务。

在「WiFi 配置」选择链路，扫描 2.4 GHz 网络、选择 SSID 并输入密码后保存。USB 使用左侧烧录器 USB 标识；BLE 使用左侧选择的设备；控制台必须选择烧录器自身的 CH343 串口，不能选择目标 MCU 串口。

当前开发版的 BLE 配网要求加密连接。首次使用时请完成 Windows 配对。已有有效配对的设备会在读写配网特征时重新建立加密；旧配对记录失效时，可在 Windows 蓝牙设置中移除设备后重新配对。

BLE 保存或清除前，运行状态下长按 BOOT 约 2 秒开放配置窗口。USB OTA 授权不能用于 BLE 配网。保存成功后设备会重启，密码保存在设备 NVS。USB 与 BLE 配网均可直接通过上位机进行。

固件 0.1.3 支持完整的 32 字节 SSID。保存或清除配网与 OTA 互斥，设备忙时请等待当前操作结束。清除会一并删除旧版固件使用的凭据键。

建议使用 USB 或 BLE 配网。控制台方式会发送包含密码 HEX 的命令，设备固件可能回显该命令；HEX 可以还原密码，不属于加密。上位机过滤回显，但无法阻止设备向其他串口监听器输出；请勿同时录制控制台。控制台响应支持分片、CR/LF 及日志混排，扫描最长等待 90 秒，其他操作 40 秒。

协议请求/响应处理见 `WireLink.Core/WifiSetupProtocol.cs`；链路实现见 `WireLink.App/Services/WifiSetupService.cs`。普通自动测试不连接硬件。
