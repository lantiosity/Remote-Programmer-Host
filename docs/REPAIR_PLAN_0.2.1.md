仅修改上位机，不改变固件、设备配置或跨端报文格式。保留既有 0.2.0 归档及工作区已有的打包变更。

|---|---|---|
| 1 | HS-01/02/03/04/19 | 请求生命周期、子进程退出、USB 候选容错、任意名称 BLE 扫描；新增超时、取消、多候选与目录合并测试 |
| 2 | HS-05/06/07/08/13 | 首次长读就绪、UART 帧解析、传输失效隔离、串口串行生命周期、DAP 带响应写入与明确溢出错误；本地假链路测试，不修改协议 |

| HS-04 | 扫描不依赖 ESP-SWD 名称，保留无名称广播，按地址选择；因此也会列出其他 BLE 设备，连接时验证服务。更名实机待验。 |
| HS-05 | 先短读状态触发协商，有限等待 MTU 后长读；损坏信息给出重新连接提示。Windows 蓝牙长读兼容性仍需实机验证。 |

| HS-07 | 不改变协议；交换串行，任一交换失败后释放连接、清空缓存并禁止复用，避免迟到响应进入下一次请求。取消后复用测试通过。 |
| HS-08 | 打开与释放使用同一异步门；回调绑定连接实例，释放期间保持占用，避免旧回调清掉新连接。TCP 并发发送/重复释放与原双向收发测试通过。 |

## 验证记录

- 本机无硬件 C# 回归 32/32，Node 回归 16/16；Release 自包含发布及资产校验、精简引擎冒烟通过。
- 已通过便携入口启动并观察到界面版本 0.2.1、后台目录 4074 个型号、多级菜单。启动计时本次 workbench_revealed 为 979 ms；这是单次本机测量，不能代表所有电脑。
- 不改动、构建或烧写固件，不执行真实目标 flash/erase/OTA。物理 BLE/USB 验收与硬件压力测试保留为后续项目。
- 发行包的 7z 完整性、逐文件解压比对、SHA256 和版本记录见 release/0.2.1/README.md。
