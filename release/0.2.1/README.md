# WireLink 0.2.1 发行文件

日期：2026-11-18。上位机审阅修复版；不改动、构建或烧写固件。旧版 0.2.0 文件保留。

- `WireLink-0.2.1-win-x64.7z`：便携版，约 203.5 MiB。完整解压后双击文件夹内的 `WireLink.exe`，不要只取出 EXE。
- `host-0.2.1-source.zip`：源码及文档快照，77 个文件，不含开发工具或运行依赖。
- `manifest.json`：源码文件清单与 SHA256。
- `WireLink-0.2.1-win-x64.manifest.json`：便携版 1500 个文件的大小、SHA256 及压缩包校验值。
- `SHA256SUMS.txt`：两个压缩包的 SHA256。

便携包适用于 Windows 10 2004 及以上 x64 / Windows 11，包含 .NET、Python/pyOCD、30 个 STM32 设备包和全部语言资源。默认使用系统 WebView2；未安装时调用微软签名的引导安装器，需要联网。安装 Edge 本身不保证已有 WebView2 Runtime。

包内顶层为 `WireLink.exe`、`使用说明.txt`、`app/`、空的 `data/`，不携带个人设置、设备历史或固件镜像。首次启动后在 data 中生成设置。语言资源在 `app/lang/`，WebView2Loader.dll 仅保留在 app 根目录。

修复包括请求超时与宿主心跳、pyOCD 退出竞态、USB 候选容错及失效连接隔离、BLE 更名发现及 DAP 带响应写入、串口生命周期、UART 配网分帧、芯片目录去重、后台取消及设置落盘恢复。发布流程新增依赖校验、精简后冒烟、备份保留和 Windows CI。逐项说明与限制见源码中的 `docs/REPAIR_PLAN_0.2.1.md`。

验证：C# 无硬件回归 32/32、Node 回归 16/16；Release 自包含构建与精简引擎导入通过。7z 完整性测试通过，解压后 1500 个文件与打包输入逐文件 SHA256 一致；源码 ZIP 与对应 Git 源文件一致。便携入口 UI 检查已观察到版本 0.2.1 与 4074 个芯片目录项。本机单次进入工作台约 979 ms，仅供参考。

真实 BLE 大块传输、首次长读和 USB 驱动异常仍需实机验收，不能视为本次实测通过。UART 控制台可能由设备回显密码命令，上位机不记录、不转发回显；建议使用 USB/BLE 配网。Windows CI 仅已配置，未在远端运行。

源码与版本元数据纳入本地提交及标签 v0.2.1；大型便携 7z 与其生成清单保留在本目录并被 Git 忽略，未上传远端。
